# portfolio-simple-website

## 📌 Overview

A simple and responsive personal portfolio website developed to introduce myself, showcase my skills and interests, and provide a way for visitors to get in touch with me.

This project was developed using fundamental web development technologies, with a focus on clean structure, simple design, and user-friendly navigation.

## ✨ Features

* Clean and simple user interface
* Home page with personal introduction
* Contact page for communication
* Navigation between pages
* Basic responsive styling
* Structured and maintainable HTML and CSS

## 🛠️ Tools & Technologies Used

| Technology             | Purpose                             |
| ---------------------- | ----------------------------------- |
| **HTML5**              | Website structure and content       |
| **CSS3**               | Styling, layout, and visual design  |
| **Visual Studio Code** | Code development and editing        |
| **Git & GitHub**       | Version control and project hosting |

## 🚀 How to View the Website

### Option 1: Run Locally

1. Clone this repository:

```bash
git clone https://github.com/your-username/your-repository-name.git
```

2. Open the project folder in **Visual Studio Code**.

3. Open `index.html` in a web browser.

4. Navigate between the **Home** and **Contact** pages using the website navigation.

### Option 2: Using VS Code Live Server

1. Open the project in **Visual Studio Code**.
2. Install the **Live Server** extension.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.
5. The portfolio will open automatically in your browser.
